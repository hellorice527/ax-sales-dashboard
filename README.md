# AX러닝랩 매출 대시보드

기업 AX 교육 매출을 CSV로 분석하는 React 대시보드입니다. 업로드한 파일과 수정한 값은 브라우저 메모리에서 처리합니다. 로그인, 데이터베이스, API 키 없이 실행할 수 있습니다.

## 로컬 실행

Node.js 24로 검증했습니다.

```sh
npm ci
npm run dev
```

## CSV 사용법

- 처음 열면 가상 거래 50건을 표시합니다. 하단에서 표준 CSV와 실습용 파일 2개를 다운로드할 수 있습니다.
- CSV 파일을 하나씩 선택하거나 드래그 앤 드롭합니다. UTF-8과 CP949 인코딩을 읽고 한글 및 영문 헤더를 인식합니다.
- 날짜, 고객사, 서비스와 매출액이 필요합니다. 매출액이 비어 있고 수량과 단가가 유효하면 곱으로 계산합니다.
- 인식되지 않거나 후보가 여러 개인 필드는 컬럼 설정에서 선택합니다. 예를 들어 `03/04/2026`처럼 의미가 불분명한 날짜는 확인 항목으로 표시됩니다. 값을 수정하면 집계에 반영됩니다.
- 유효한 거래를 요약 카드, 월별 및 서비스별 차트, 검색·정렬 가능한 표에서 확인합니다. 정리된 CSV는 표의 검색 조건과 관계없이 유효한 거래 전체를 내보냅니다.

## 테스트와 빌드

```sh
npm test
npm run build
npm run preview
```

Vercel에서 Vite 프레임워크, `npm run build` 빌드 명령, `dist` 출력 디렉터리를 사용하도록 설정했습니다. 환경 변수는 필요하지 않습니다.
